# گزارش بررسی زیرساخت و بک‌اند ورود

تاریخ: ۲۰۲۶-۰۹-۲۲

## نتیجهٔ محلی

- Node 22.23.2 به‌صورت محلی در ابزارهای موقت نصب شد؛ نصب سراسری دستگاه تغییر نکرد.
- فایل lock ناقصِ حاصل از نصب قطع‌شده بازسازی شد؛ ورودی وابستگی بدون نسخه ندارد.
- قوانین ESLint از وابستگی به parser داخلی Next جدا شدند؛ قوانین Next، React Hooks و دسترس‌پذیری مستقیماً فعال‌اند.
- lint، بررسی سخت‌گیرانهٔ TypeScript و قالب‌بندی موفق شدند.
- هشت آزمون مستقل از دیتابیس موفق شدند.
- نه آزمون یکپارچه روی MongoDB واقعی موفق شدند؛ دیتابیس تصادفی اختصاصی بعد از آزمون حذف شد.
- build قراردادها، بک‌اند و فرانت با Next.js 16.3.5 موفق شد.

## پوشش مهم آزمون‌ها

یکسان‌سازی شماره‌ها و ارقام، رد ورودی اضافی برای تخصیص نقش، اعتبار تنظیمات، ساخت حساب پس از تأیید، ویژگی‌های کوکی، ذخیرهٔ هش کد و نشست، جلوگیری از استفادهٔ دوباره و هم‌زمان کد، سقف تلاش هم‌زمان، انقضای کد و نشست مستقل از پاک‌سازی TTL، ارسال مجدد، Origin نامعتبر، شکست سرویس پیامک، حساب مسدود و شمارندهٔ اتمیک سهمیه.

## حدود این نتیجه

- اتصال پیامک واقعی و فرم ورود فرانت هنوز پیاده نشده‌اند؛ آزمون مرورگر برای جریان ورود انجام نشده است.
- سرویس پیش‌فرض پیامک عمداً غیرفعال است و پاسخ ۵۰۳ می‌دهد.
- نتیجهٔ محلی به معنی موفقیت اجرای GitHub Actions نیست؛ وضعیت هر اجرای CI باید روی همان commit بررسی شود.
- تنظیم شبکهٔ استقرار، عامل دوم پنل فروشنده و آزمون بار باقی مانده‌اند. سیستم فروش آمادهٔ انتشار عمومی اعلام نمی‌شود.

## بازتولید

با Node ۲۲ به‌روز و MongoDB در دسترس:

```powershell
npm ci
npm run check
npm run test:integration
npm run build
```

جزئیات تنظیمات و آزمون دیتابیس در authentication.md آمده است.
