# گزارش بررسی پروژه

## ورود با موبایل و رابط کاربری — ۲۰۲۶-۰۹-۲۲

- Node 22.23.2 محلی استفاده شد؛ نصب سراسری تغییر نکرد.
- lint، TypeScript، هشت آزمون مستقل و قالب‌بندی موفق شدند.
- نه آزمون یکپارچه روی MongoDB واقعی موفق شدند.
- هر پنج آزمون Playwright در Edge موفق شدند: اعتبارسنجی و نبود سرویس پیامک، ورود با ارقام فارسی و کد اشتباه و صحیح، حفظ نشست و خروج، هدایت مهمان، ارسال مجدد و انقضای کد.
- مرورگر به Next و Express واقعی متصل بود؛ فقط فرستندهٔ پیامک آزمایشی بود. دیتابیس‌های آزمایشی اختصاصی در پایان پاک شدند.
- اسکرین‌شات موبایل ۳۹۰×۸۴۴ و حساب دسکتاپ بازبینی شدند؛ سرریز افقی موبایل نیز در آزمون بررسی شد.
- build قراردادها، بک‌اند و فرانت با Next.js 16.3.5 موفق شد؛ مسیرهای خانه، ورود و حساب ساخته شدند.

دو اشکال در اجرای اولیهٔ تست رفع شد: انتخاب مبهم پیام خطا به ناحیهٔ حساب محدود شد و خروجی Next آزمون در .next-e2e از اجرای توسعه جدا شد. محدودیت سهمیهٔ سامانهٔ تأیید خودکار که اجرای قبلی را متوقف کرده بود، در این نوبت مانع اجرا نشد.

نتایج بالا محلی‌اند و موفقیت GitHub Actions را تضمین نمی‌کنند. CI برای آزمون مرورگر از Chromium استفاده می‌کند.

## باقی‌مانده برای انتشار

اتصال پیامک واقعی، تنظیم شبکهٔ استقرار، عامل دوم پنل فروشنده، مدیریت مجوزها و آزمون بار. فروش، پرداخت، قیمت‌گذاری، کیف پول و تسویه هنوز پیاده نشده‌اند؛ سیستم فروش آمادهٔ انتشار عمومی نیست.
